---
description: Open FX Comparison Page Preview
---
This workflow opens the FX comparison page in the browser for quick preview.

1. Ensure the development server is running on port 8080
// turbo
```powershell
npm run dev
```

2. Open the FX comparison page in the browser
   - URL: `http://localhost:8080/fx-comparison`
   - This page shows the FX account comparison with official company names and the prominent "12" in the title
